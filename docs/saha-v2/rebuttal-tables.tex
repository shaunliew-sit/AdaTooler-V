% $\alpha{=}0$ variant (i.e. $R = R_{\text{format}}\cdot R_{\text{outcome}}$, the
% tool-gain term removed), trained from the same SFT initialisation and evaluated
% on the complete test sets of all four benchmarks (92{,}446 samples).
% Removing the tool-gain term costs \textbf{1.94 AR} on HICO-DET grounding and
% \textbf{3.36 AR} on SWiG-HOI grounding (Table~\ref{tab:reward-ablation-grounding}),
% with consistent drops at every IoU threshold and every object-size bucket.
% We additionally ablate the SFT stage (direct GRPO from the base model): that
% variant invokes the zoom tool on essentially every sample
% (Table~\ref{tab:tool-selectivity}) while earning near-zero tool-gain during
% training, confirming that the difficulty-aware SFT -- not the RL objective
% alone -- is what establishes selective tool use.
